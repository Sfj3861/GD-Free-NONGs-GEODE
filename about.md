# GD Free NONGs

A community-powered alternative music manager for Geometry Dash.

This mod is designed to work with the GD Free NONGs web library. The long-term workflow is: choose a permitted alternative audio version on the website, synchronize it to the local installation, and let the mod resolve the selected local audio when Geometry Dash requests the associated song.

The current development build is an initialization foundation. It does not yet download or replace music.
